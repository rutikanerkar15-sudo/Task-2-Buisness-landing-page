# Craftia — Business Landing Page

Craftia is a responsive, conversion-focused business landing page designed for a custom furniture and bespoke interior design studio. The page combines strategic marketing layout principles with semantic HTML5 and modern CSS to deliver an engaging user experience across desktop and mobile devices.

---

## 🎯 Strategic Layout & Design Hierarchy

The landing page is engineered around a high-converting **Problem → Value → Services → Trust → Action** narrative flow:

1. **Above the Fold (Hero Section):** Instant brand clarity with a bold value proposition, high-impact background visuals, and action-oriented CTAs ("Explore Collections", "Book Consultation").
2. **Problem & Value Proposition:** Addresses common pain points of mass-produced furniture versus handcrafted, tailored living solutions.
3. **Services Showcase:** Clear breakdown of custom furniture manufacturing, interior blueprint planning, and sustainable wood sourcing.
4. **Social Proof & Trust:** Highlights certifications, 10-year durability warranties, and customer testimonials.
5. **Action (Contact Form):** A streamlined contact section with built-in HTML5 form validation to convert visitors into inquiries.

---

## 🚀 Key Features & Standards

* **Responsive Design:** Fluid layouts using modern CSS Flexbox and Grid that adapt seamlessly from wide desktop displays to mobile viewports.
* **Accessible Contact Form:** Includes fields for Name, Email, Phone/Business Type, Message textarea, and HTML5 validation attributes (`required`, `type="email"`, `pattern`).
* **Design Consistency:** Unified design system utilizing CSS variables for border-radius, elevation shadows, typography scaling, and high-contrast readable color palettes.
* **Micro-Interactions:** Smooth hover states and card transition animations to enhance user interactivity without compromising performance.

## 🛠️ Built With

* **HTML5:** Semantic architecture (`<header>`, `<main>`, `<section>`, `<form>`, `<footer>`).
* **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, media queries, and transition effects.
* **Font Awesome:** Vector iconography for feature highlights and contact details.
